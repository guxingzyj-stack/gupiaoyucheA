# A股智能分析预测系统 — 安装使用说明

## 环境要求
- Windows 10/11
- Python 3.10 或以上（推荐 3.11）
- 内存：4GB以上（快速模式）/ 8GB以上（完整模式）
- 网络：需要能访问互联网（获取股票数据）

## 安装步骤

### 第一步：安装 Python
如未安装，请到 https://www.python.org/downloads/ 下载安装
安装时勾选「Add Python to PATH」

### 第二步：安装依赖
双击运行「安装依赖.bat」，等待安装完成（约5~15分钟）

### 第三步：启动软件
- 「启动桌面版.bat」→ 电脑浏览器访问 http://localhost:8501
- 「启动手机版.bat」→ 手机浏览器访问 http://电脑IP:8502
- 「启动全部.bat」  → 同时启动两个版本

## 功能说明

### 快速模式（默认，约30秒）
- 使用 XGBoost 模型预测
- 适合日常快速查看

### 完整模式（约2分钟）
- 使用 LSTM + XGBoost + Prophet 三模型融合
- 预测更准确，耗时更长

## 常见问题

Q: 手机无法访问？
A: 确保手机和电脑在同一个WiFi，防火墙开放8502端口

Q: 安装依赖失败？
A: 尝试换源：pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

Q: 数据获取失败？
A: 检查网络连接，akshare数据源需要访问互联网
